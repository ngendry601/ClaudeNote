## 1. Méthodes de l'épreuve (4 h)

::: Question juridique : quelle méthode ?
==Syllogisme : FAITS → PROBLÈME → RÈGLE → SOLUTION==
- **Faits** : qui contre qui, que s'est-il passé, **qualifiés juridiquement** (« M. X, acheteur » ; « la société Y, prestataire »)
- **Problème de droit** : question **générale, sans les noms**
- **Règle de droit** : article + **conditions énumérées**
- **Solution** : appliquer **chaque condition** aux faits → conclure oui / non
!! Pas de recopie du document dans les faits.
:::

::: Question d'analyse : comment structurer la réponse ?
==Notion définie → fait précis du doc (n° du doc) → conclusion==
!! Sans fait du dossier = moitié des points.
:::

::: Verbes de consigne : identifier, qualifier, caractériser, analyser, justifier
- **Identifier** = nommer
- **Qualifier** = donner le nom juridique / la catégorie
- **Caractériser** = décrire les traits
- **Analyser** = expliquer et justifier
- **Justifier** = prouver avec le doc
:::

::: Formule du taux d'évolution
==(V arrivée − V départ) / V départ × 100==
!! Toujours diviser par la valeur de **départ**.
:::

::: Formules : part, valeur ajoutée, seuil d'abonnement
- **Part** = partie / total × 100
- **VA** = CA − consommations intermédiaires
- **Seuil d'abonnement** = coût annuel / prix unitaire, arrondi à l'entier **supérieur**
- Mensuel × 12 = annuel
:::

::: Présenter un calcul : les 4 étapes
==Formule → calcul posé → résultat + unité → phrase d'interprétation==
:::

::: Développement structuré : intro, plan, arguments
- **Intro** : accroche, définitions des mots du sujet, problématique, annonce du plan
- « Est-ce… ? » → plan **oui / mais** (dialectique)
- « En quoi… ? » → plan **thématique**
- 2 parties × 2 sous-parties ; chaque argument = **notion + exemple**
- **Conclusion** nuancée + ouverture
:::

## 2. Économie — mots à savoir par cœur

### Agents et circuit

::: Agent économique : définition et types
Centre de **décision autonome**.
- **Ménages** : consommer, épargner
- **Entreprises** : produire
- **Administrations** : services non marchands, redistribuer
- **Banques / assurances** : financer, couvrir
- **ISBLSM / associations**, **reste du monde**
:::

::: Circuit économique
Flux **réels** (biens, travail) en ==sens inverse== des flux **monétaires** (salaires, paiements, impôts).
:::

::: Valeur ajoutée : calcul et partage
==VA = CA − consommations intermédiaires==
Partagée entre :
- **Salariés** → salaires
- **État** → impôts
- **Prêteurs** → intérêts
- **Actionnaires** → dividendes
- **Entreprise** → autofinancement
:::

::: PIB
Somme des **VA** produites **sur le territoire** en **1 an**.
:::

::: Les 3 modes de financement
- **Autofinancement** (CAF)
- **Indirect** : crédit bancaire → la banque est **intermédiaire**
- **Direct** : actions, obligations, levée de fonds auprès d'investisseurs (marché financier si cotée)
:::

### Marché et concurrence

::: Marché et prix d'équilibre
Rencontre **offre / demande** → ==prix d'équilibre==
Demande ↑ ou offre ↓ → prix ↑
:::

::: Concurrence pure et parfaite : les 5 conditions
1. **Atomicité**
2. **Homogénéité** des produits
3. **Libre entrée / sortie**
4. **Transparence** de l'information
5. **Mobilité** des facteurs
:::

::: Monopole, oligopole, concurrence monopolistique
- **Monopole** : 1 offreur, fixe le prix
- **Oligopole** : quelques offreurs, risque d'**entente**
- **Concurrence monopolistique** : produits **différenciés**
:::

::: Barrière à l'entrée
Obstacle qui **empêche un nouvel entrant** : capital, brevet, réglementation, effet de réseau.
:::

::: Économies d'échelle et coût marginal
- **Économies d'échelle** : le coût **unitaire baisse** quand la quantité produite augmente
- **Coût marginal** : coût d'**une unité de plus**
:::

### Défaillances du marché

::: Externalité : définition et exemples
Effet (positif ou négatif) de l'activité d'un agent sur un autre ==sans compensation par le prix==.
- **Négative** : pollution d'une usine, CO₂, eau et électricité des data centers
- **Positive** : formation des salariés qui profite à d'autres entreprises, chaleur récupérée d'un data center, recherche, vaccination
!! Le critère clé est l'absence de compensation **par le prix**.
:::

::: Comment internaliser une externalité ?
- **Négative** : **taxe** (pollueur-payeur, taxe pigouvienne), **norme** / interdiction, **marché de quotas** (droits à polluer)
- **Positive** : **subvention**
:::

::: Asymétrie d'information
Une partie en sait plus que l'autre (vendeur de voiture d'occasion).
- **Antisélection** : **avant** le contrat
- **Aléa moral** : **après** le contrat
→ Réponses : garantie, label, obligation d'information
:::

::: Bien collectif
==Non rival + non exclusif== (éclairage public, défense) → produit par l'**État**.
:::

::: Effet de réseau : direct et croisé
Un utilisateur de plus augmente la valeur :
- **Direct** : pour **tous** les utilisateurs
- **Croisé** : pour **l'autre face** de la plateforme
:::

### État et régulation

::: Musgrave : les 3 fonctions de l'État
- **Allocation** : biens collectifs
- **Redistribution** : réduire les inégalités
- **Stabilisation** : croissance, emploi, prix
:::

::: Politique budgétaire vs politique monétaire
- **Budgétaire** : l'**État** (dépenses, impôts)
- **Monétaire** : la **BCE** (taux directeurs, objectif ==inflation 2 %==)
:::

::: Régulation
Action publique qui **encadre un marché** : Autorité de la concurrence, **ARCEP**, **CNIL**.
:::

### Numérique

::: Dématérialisation vs automatisation
- **Dématérialisation** : support physique → flux numérique
- **Automatisation** : traitement **sans humain** (format structuré)
Ex. : PDF par mail = dématérialisé, **pas automatisé**
!! Dématérialisation ≠ automatisation.
:::

::: Désintermédiation vs réintermédiation
- **Désintermédiation** : un intermédiaire **disparaît**
- **Réintermédiation** : un **nouveau** arrive (plateforme, Spotify, plateforme agréée de e-facture)
!! Ne pas confondre les deux.
:::

::: Plateforme / marché biface et place de marché
- **Marché biface** : sert **2 groupes**, une face paie, l'autre souvent gratuite (Doctolib)
- **Place de marché** : met en relation **vendeurs tiers** et acheteurs
:::

::: Modèles économiques du numérique
- **Freemium** : gratuit + premium → indicateur = ==taux de conversion==
- **Abonnement**, **publicité**, **commission**
- **Prosommateur** (Toffler) : consommateur qui produit
- Économie **collaborative** · économie **de l'usage** (usage > propriété)
:::

::: Licorne et décacorne
- **Licorne** : start-up **non cotée** > **1 Md$**
- **Décacorne** : > **10 Md$**
!! Valorisation ≠ CA ≠ volume de transactions.
:::

::: B to B, B to C, C to C, B to G, G to C
Types d'échanges classés selon le **statut des acteurs** : Business (entreprise), Consumer (particulier), Government (administration).
:::

### Travail et mondialisation

::: Les 3 types de chômage
- **Frictionnel** : transition entre 2 emplois
- **Conjoncturel** : crise
- **Structurel** : inadéquation des compétences
+ **Polarisation** de l'emploi
:::

::: Les formes de flexibilité
- **Quantitative externe** : CDD, intérim
- **Quantitative interne** : horaires
- **Qualitative** : polyvalence
- **Salariale** · **externalisation**
:::

::: Destruction créatrice, déversement, types d'innovation
- **Destruction créatrice** : Schumpeter
- **Déversement** : Sauvy
- Innovation de **produit**, **procédé**, **organisation**, **commercialisation**
:::

::: FMN, IDE, DIPP et compétitivité
- **FMN** : firme multinationale · **IDE** : filiale à l'étranger · **DIPP** / chaîne de valeur mondiale
- Compétitivité **prix** (coûts, change) / **hors prix** (qualité, innovation, image)
:::

## 3. Droit — mots à savoir par cœur

### Bases

::: Hiérarchie des normes
==Constitution > traités / droit UE > lois > règlements > contrats==
+ jurisprudence, conventions collectives
:::

::: Personne physique / personne morale
Titulaires de droits avec un **patrimoine propre**.
Personne morale = **société**, **association**.
:::

::: Droit objectif / droits subjectifs
- **Droit objectif** : les **règles**
- **Droits subjectifs** : **prérogatives** d'une personne (patrimoniaux, extrapatrimoniaux)
:::

### Le contrat — formation

::: Contrat (art. 1101) et liberté contractuelle (art. 1102)
- **1101** : accord de volontés qui ==crée des obligations==
- **1102** : liberté contractuelle, dans le respect de l'**ordre public**
:::

::: Pourparlers : quelles obligations ?
Libres, mais :
- **Bonne foi** (1104)
- **Obligation d'information** (1112-1)
- **Confidentialité** (1112-2)
→ Rupture abusive = responsabilité **extracontractuelle**
:::

::: Avant-contrats et formation du contrat
- Avant-contrats : **pacte de préférence**, **promesse unilatérale**, **promesse synallagmatique**
- ==Offre (précise + ferme) + acceptation = contrat formé==
:::

::: Validité du contrat (art. 1128) : les 3 conditions
1. **Consentement** des parties
2. **Capacité** de contracter
3. **Contenu licite et certain**
:::

::: Vices du consentement (art. 1130)
- **Erreur** : sur les qualités essentielles, **excusable**
- **Dol** (1137) : manœuvres, mensonge ou silence volontaire pour tromper, **déterminant**
- **Violence** : contrainte physique ou morale, y compris ==abus de dépendance économique== (1143)
!! Dol = nullité, pas résolution.
:::

::: Nullité : définition, relative ou absolue
Sanction d'une **condition de formation** → le contrat est ==censé n'avoir jamais existé== (restitutions).
- **Relative** : protège une partie (vice du consentement), **5 ans**
- **Absolue** : intérêt général (contenu illicite)
:::

### Le contrat — effets et inexécution

::: Force obligatoire, imprévision, effet relatif
- **Force obligatoire** (1103) : le contrat « ==tient lieu de loi== » ; modification d'un commun accord (1193)
- **Imprévision** (1195) : changement imprévisible → **renégociation**
- **Effet relatif** : n'engage **que les parties**
:::

::: Clause pénale vs clause limitative de responsabilité
- **Pénale** : indemnité **forfaitaire** fixée d'avance (réductible par le juge si excessive)
- **Limitative** : **plafonne** les dommages et intérêts ; écartée si **faute lourde ou dolosive** ou si elle vide l'**obligation essentielle** (1170)
!! Clause pénale (forfait) ≠ clause limitative (plafond).
:::

::: Clauses : réserve de propriété, résolutoire, attributive de compétence
- **Réserve de propriété** : propriété transférée au **paiement complet**
- **Résolutoire** : fin **automatique** si inexécution
- **Attributive de compétence** : tribunal choisi (entre commerçants)
- Aussi : confidentialité, non-concurrence, indexation
:::

::: Inexécution (art. 1217) : les 5 sanctions
1. **Exception d'inexécution**
2. **Exécution forcée**
3. **Réduction du prix**
4. **Résolution** (fin du contrat)
5. **Dommages et intérêts**
:::

::: Résolution ou nullité ?
- **Résolution** = problème d'**exécution**
- **Nullité** = problème de **formation**
!! Nullité (formation) ≠ résolution (exécution).
:::

::: Obligation de moyens vs de résultat
- **Moyens** : tout faire, **faute à prouver**
- **Résultat** : seul le **résultat** compte
→ Prestataire informatique : souvent moyens + ==obligation de conseil==
:::

### Responsabilité civile

::: Responsabilité civile : les 3 conditions
==Fait générateur + dommage + lien de causalité==
Dommage : **certain, direct, personnel**
:::

::: Responsabilité contractuelle vs extracontractuelle
- **Contractuelle** : inexécution d'un contrat
- **Extracontractuelle** : faute (**1240**), négligence (**1241**), fait des choses / des personnes dont on répond, ex. l'employeur pour ses salariés (**1242**)
:::

::: Causes d'exonération de responsabilité
- **Force majeure** : ==imprévisible, irrésistible, extérieure==
- **Faute de la victime**
- **Fait d'un tiers**
:::

::: Responsabilité pénale
Infraction **punie par la loi** (amende, prison).
La **personne morale** peut aussi être pénalement responsable.
:::

### Propriété intellectuelle

::: Droit d'auteur : objet, conditions, durée
- **Protège** : œuvre de l'esprit, **logiciel**, site web
- **Conditions** : ==originalité + forme== (pas les idées)
- **Durée** : dès la création, **sans dépôt** ; patrimonial **70 ans après la mort** ; droit moral **perpétuel**
:::

::: Brevet : objet, conditions, durée
- **Protège** : invention technique
- **Conditions** : **nouveauté**, **activité inventive**, **application industrielle**
- **Durée** : dépôt **INPI**, ==20 ans==, redevances annuelles
!! Brevet 20 ans non renouvelable ≠ marque 10 ans renouvelable.
:::

::: Marque : objet, conditions, durée
- **Protège** : signe distinctif (nom, logo, son)
- **Conditions** : **distinctive**, **licite**, **disponible**
- **Durée** : dépôt **INPI**, ==10 ans renouvelable à l'infini==
:::

::: Dessins et modèles / bases de données
- **Dessins, modèles** : apparence d'un produit ; nouveauté, caractère propre ; **5 ans renouvelables, max 25 ans**
- **Base de données** : travail du producteur ; gros investissement ; **15 ans** (droit *sui generis*)
:::

::: Comment est protégé un logiciel ?
Par le ==droit d'auteur==, pas par brevet (en principe).
Créé par un **salarié dans ses fonctions** → droits à l'**employeur**.
!! Logiciel = droit d'auteur, pas brevet.
:::

::: Cession vs licence
- **Cession** : on **vend** le droit
- **Licence** : on **autorise l'usage** contre redevance
→ Logiciel libre (GPL…)
:::

::: Contrefaçon et concurrence déloyale
- **Contrefaçon** : atteinte à un droit de PI → sanction **civile** (D&I) et **pénale** (jusqu'à ==3 ans et 300 000 €==)
- Sans droit de PI → **concurrence déloyale** (1240) : dénigrement, confusion, parasitisme
:::

### Numérique et données

::: Donnée personnelle et donnée sensible
- **Donnée personnelle** : identifie une personne **directement ou indirectement** (nom, IP, photo)
- **Donnée sensible** (art. 9) : santé, origine, opinions, religion, syndicat, biométrie, vie sexuelle → ==interdite sauf exception==
:::

::: Principes du RGPD
- **Licéité**, **finalité**, **minimisation**, exactitude
- **Durée de conservation** limitée, **sécurité**
- **Responsabilité** (accountability, registre des traitements)
- Consentement ==libre et éclairé==
:::

::: RGPD : droits, acteurs, sanctions
- **Droits** : accès, rectification, effacement (oubli), opposition, **portabilité**, limitation
- **Acteurs** : responsable de traitement, sous-traitant, DPO, CNIL
- **Sanction** : ==4 % du CA mondial ou 20 M€==
- Violation de données → notification CNIL sous **72 h**
:::

::: Contrats informatiques et SLA
Licence, maintenance, **infogérance**, **SaaS / cloud**.
**SLA** = niveau de service : disponibilité, temps de réponse / rétablissement, **pénalités**.
:::

::: Preuve et signature électroniques
- **Preuve électronique** (1366) : même valeur que le papier si ==auteur identifié + intégrité==
- **Signature électronique** : règlement **eIDAS**
:::

::: Cybercriminalité et régulation du numérique
- Accès / maintien frauduleux dans un **STAD** (art. **323-1** C. pén.)
- **NIS2** (cybersécurité) · **DMA** (contrôleurs d'accès, a priori, 10 % CA) · **DSA** (contenus)
:::

### Concurrence

::: Entente et abus de position dominante
- **Entente** (L420-1) et **abus de position dominante** (L420-2) : interdits
- Abus : vente liée, exclusivité, prix prédateurs
- Contrôle des concentrations ; **Autorité de la concurrence** (a posteriori, amende)
!! La position dominante est légale : c'est l'**abus** qui est sanctionné.
:::

### Sociétés et travail

::: Formes de sociétés : EI, EURL/SARL, SAS/SASU, SA
- **EI** : patrimoine pro séparé depuis 2022
- **EURL/SARL** : gérant, responsabilité **limitée aux apports**
- **SAS/SASU** : **statuts libres**, président
- **SA** : **37 000 €** min., cotable
:::

::: Contrat de travail : les 3 éléments
==Prestation + rémunération + lien de subordination==
- Requalification d'un indépendant possible (Uber 2020)
- CDI, CDD / intérim (cas limités), apprentissage
:::

::: Pouvoirs de l'employeur et rupture du contrat
- **Pouvoirs** : direction, réglementaire (règlement intérieur **≥ 50 salariés**), disciplinaire
- **Rupture** : démission, licenciement (**cause réelle et sérieuse**), rupture conventionnelle
- Télétravail, droit à la déconnexion, **CSE ≥ 11 salariés**, convention collective
:::

## 4. Management — mots à savoir par cœur

### Organisation et finalités

::: Finalités de l'entreprise et RSE
- **Économique** (profit, pérennité) · **sociale** (emploi) · **sociétale**
- **RSE** : intégrer ==volontairement== les enjeux sociaux et environnementaux
- **Drucker** : profit = conséquence de la satisfaction client
:::

::: Partie prenante (Freeman) et Mendelow
Acteur qui ==affecte ou est affecté== par l'entreprise (internes / externes).
**Mendelow** : pouvoir × intérêt
:::

::: Gouvernance et obligations récentes
- Gouvernance **actionnariale** / **partenariale**
- **Loi PACTE 2019** : raison d'être, société à mission
- **Devoir de vigilance** 2017 · **CSRD**
:::

::: ESS et tailles d'entreprise
- **ESS** : associations, coopératives, mutuelles
- **TPE** < 10 · **PME** < 250 · **ETI** < 5 000
:::

::: Logique entrepreneuriale vs managériale
- **Entrepreneuriale** : opportunité, risque, innovation
- **Managériale** : planifier, organiser, diriger, contrôler
:::

::: Structures et coordination (Mintzberg)
- **Structures** : simple, fonctionnelle, divisionnelle, matricielle, en réseau / par projet
- **Coordination** : ajustement mutuel, supervision directe, standardisation
:::

::: Performance : efficace, efficient, pertinent
- **Efficace** : objectif atteint
- **Efficient** : avec moins de ressources
- **Pertinent** : moyens adaptés
→ Performance globale, tableau de bord, KPI
:::

### Décision

::: Ansoff : les 3 niveaux de décision
- **Stratégique** : long terme, direction, irréversible, rare
- **Tactique** : moyen terme, cadres
- **Opérationnelle** : court terme, quotidienne, réversible
!! Toujours citer 3 critères pour justifier le niveau.
:::

::: Simon : modèle IMC et rationalité limitée
- **I**ntelligence : problème, infos
- **M**odélisation : solutions
- **C**hoix
==Rationalité limitée → solution satisfaisante, pas optimale==
Facteurs de contingence internes / externes
:::

### Stratégie — démarche et diagnostic

::: Stratégie : définition et hiérarchie des buts
Choix à **long terme** qui engagent l'entreprise pour obtenir un ==avantage concurrentiel durable==.
Finalité > but > **objectif** (précis, chiffré, daté)
!! Objectif = chiffré et daté ; sinon c'est un but.
:::

::: Démarche stratégique : LCAG et Mintzberg
- **LCAG 1965** : diagnostic → choix → mise en œuvre → contrôle (boucle)
- **Mintzberg** : délibérée + **émergente** = réalisée
:::

::: PESTEL
Analyse **macro** (environnement indirect) → opportunités / menaces
==Politique, Économique, Socioculturel, Technologique, Écologique, Légal==
!! Les concurrents ne vont pas dans le PESTEL → 5 forces de Porter.
:::

::: 5 forces de Porter (1979)
Analyse **micro** (le secteur) :
1. Rivalité entre concurrents
2. Nouveaux entrants
3. Produits de substitution
4. Pouvoir des clients
5. Pouvoir des fournisseurs
(+ État) → forces fortes = secteur ==peu attractif==
:::

::: Ressources et compétence distinctive
- **Ressources** (Penrose) : tangibles / intangibles
- **Compétence distinctive** (Hamel et Prahalad) : valeur perçue, **rare**, **difficile à imiter**
!! Ressource (ce qu'on a) ≠ compétence (ce qu'on sait faire) ≠ FCS (exigence du marché).
:::

::: Chaîne de valeur (Porter 1985)
- **5 activités principales** : logistique amont, production, logistique aval, vente, services
- **4 activités de soutien** : infrastructure, GRH, développement technologique / SI, achats
:::

::: FCS et SWOT
- **FCS** : ce qu'il faut ==maîtriser pour réussir== sur un marché
- **SWOT** : forces / faiblesses (**internes**) + opportunités / menaces (**externes**)
!! Faiblesse (interne) ≠ menace (externe) : le critère est l'origine, pas le négatif.
:::

### Stratégie — choix

::: Options stratégiques
- **Spécialisation** · **recentrage**
- **Diversification liée** (synergies) / **conglomérale** (sans lien)
- **Intégration verticale** amont / aval
- **Externalisation** (→ SLA)
:::

::: Matrice d'Ansoff
Produits × marchés :
- **Pénétration** (produit actuel, marché actuel)
- **Développement de produits**
- **Développement de marchés**
- **Diversification** (nouveau produit, nouveau marché)
:::

::: DAS et stratégies génériques de Porter
- **DAS** : produits avec mêmes clients, concurrents, FCS
- **Porter** : domination par les **coûts**, **différenciation**, **focalisation** (niche)
!! Risque : l'enlisement (ne pas choisir).
:::

::: Matrice BCG
Croissance du marché × part de marché relative
- **Vedette** · **Vache à lait** · **Dilemme** · **Poids mort**
:::

::: Modes de croissance
- **Interne** (organique) : lente, contrôlée
- **Externe** (fusion, acquisition) : rapide, coûteuse
- **Conjointe** : alliance, joint-venture, franchise
:::

::: Modes d'internationalisation
**Exportation** · **IDE** (investissement direct à l'étranger) · **contractuelle** (licence, franchise)
:::

### Ressources humaines

::: Maslow et Herzberg
- **Maslow** : physiologique, sécurité, appartenance, estime, accomplissement
- **Herzberg** : facteurs d'**hygiène** (évitent l'insatisfaction) / **moteurs** (motivent)
:::

::: Likert et outils RH
- **Likert** : autoritaire, paternaliste, consultatif, participatif
- **Outils** : GEPP, formation, marque employeur, fidélisation, QVCT
:::

## 6. Pièges à ne pas faire

::: Piège : les concurrents vont-ils dans le PESTEL ?
**Non** → ils relèvent des ==5 forces de Porter== (rivalité).
:::

::: Piège : faiblesse ou menace ?
- **Faiblesse** = **interne**
- **Menace** = **externe**
==Le critère est l'origine, pas le caractère négatif.==
:::

::: Piège : dol → nullité ou résolution ?
==Nullité== : le dol est un vice du consentement, donc un problème de **formation**.
:::

::: Piège : CA, volume de transactions, valorisation
Trois notions **différentes** : CA ≠ volume de transactions ≠ valorisation.
:::

::: Piège : que doit contenir chaque réponse ?
Toujours ==un fait du document== (avec son numéro).
:::

::: Piège : position dominante interdite ?
**Non**, elle est **légale**. C'est l'==abus== de position dominante qui est sanctionné (L420-2).
:::
